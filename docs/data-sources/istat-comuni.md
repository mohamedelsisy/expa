# ISTAT — Elenco dei comuni italiani (geography)

Dataset key: `istat-comuni` · verified: 2026-10-11

## Source
- Publisher: ISTAT (Istituto nazionale di statistica).
- Landing page: https://www.istat.it/classificazione/codici-dei-comuni-delle-province-e-delle-regioni/ (also reachable as https://www.istat.it/it/archivio/6789).
- Permanent file link (unchanged at every ISTAT update): https://www.istat.it/storage/codici-unita-amministrative/Elenco-comuni-italiani.xlsx
- Edition imported: sheet "CODICI al 21_02_2026" (list updated 21 February 2026; file last-modified 26 Feb 2026), 7,894 comuni.
- The old CSV at `.../Elenco-comuni-italiani.csv` is stale (last modified 26 Jan 2024) and is NOT used; ISTAT now publishes the permalink only as XLSX, so the importer ships a small dependency-free XLSX reader (`App\Domains\GeoImport\Support\XlsxReader`).

## Field mapping (sheet columns)
| ISTAT column | Target |
|---|---|
| A Codice Regione | `cities.region_id` via `regions.code` (same 2-digit ISTAT code); also fills `regions.istat_code` |
| E Codice Comune formato alfanumerico (6 digits) | `cities.istat_code` (upsert key, unique) |
| G Denominazione in italiano | `city_translations` locale `it` (name) |
| O Sigla automobilistica | `cities.province_code` |
| N Flag capoluogo | `cities.is_province_capital` |
| K Denominazione Regione | only compared with the regions' `it` name (mismatch -> warning, never overwritten) |
| (run) | `cities.source_license`, `cities.source_verified_at` = fetch date; full provenance in `data_import_runs` |

`cities` has no lifecycle/source_name/source_url columns (geography is reference data), so `Lifecycle` does not apply; the source URL, licence, edition and checksum are on the `data_import_runs` row. No Arabic/English names are created: the API falls back ar -> en -> it. The 16 curated cities keep their slug and ar/en/it names (matched by slug + region; ISTAT data is attached, never duplicated). The `it` name of a curated city is never overwritten.

Slugs: ASCII slug of the Italian name (apostrophes become hyphens: `reggio-nell-emilia`). Homonyms anywhere in the file (e.g. two "Livo") always get the province sigla (`livo-co`, `livo-tn`), independent of `--all`, so slugs do not change between scopes. Existing cities never change slug.

## Commands
```
php artisan expa:import:istat-comuni                 # download + import the ~119 capoluoghi (province capitals)
php artisan expa:import:istat-comuni --dry-run       # parse + validate, write nothing
php artisan expa:import:istat-comuni --file=/path/Elenco-comuni-italiani.xlsx
php artisan expa:import:istat-comuni --all           # every comune (~7,900) -- see limitations
php artisan expa:import-runs --dataset=istat-comuni
```
Recommended schedule: monthly, e.g. `Schedule::command('expa:import:istat-comuni')->monthlyOn(3, '04:30')->withoutOverlapping()`.

## Scope decision and limitations
- Default scope = capoluoghi (flag N = 1): 119 in the 21/02/2026 list (107 provinces plus metropolitan cities and Sardinian/Sicilian territorial units, per ISTAT's flag).
- `GET /api/v1/cities` is unpaginated, capped at `expa.limits.cities_max` (1000) and the web dropdowns load it whole. Importing all 7,894 comuni would silently truncate that list (first 1000 by id) and bloat dropdowns, so `--all` is opt-in and should only be used together with a paginated/typeahead cities API (not part of this task).
- Municipalities that disappear from the source (mergers) are not hard-deleted and not flagged (cities has no status column); the importer prints a warning with the count.
- Region names in the ISTAT sheet use the bilingual official forms (e.g. "Valle d'Aosta/Vallée d'Aoste"); comparison uses the part before "/".
- Dry-run cannot detect slug collisions between rows of the same run (nothing is written).
