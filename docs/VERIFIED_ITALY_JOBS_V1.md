# Verified Italy Jobs V1

Checked on: 2026-10-10

This starter pack adds five job records sourced from individual employer-owned Amazon Jobs pages. It stores only concise summaries, a few structured fields, and the original application URL; it does not copy full vacancy descriptions.

## Listings included

- Area Manager, FC Operations — Alessandria — €46,000 gross/year — [official posting](https://www.amazon.jobs/en/jobs/10409907/area-manager-fc-operations)
- RME Automation Engineer — Torrazza Piemonte — €42,800 gross/year — [official posting](https://www.amazon.jobs/en/jobs/10555833/rme-automation-engineer)
- HR Specialist with Italian & English, 12-month contract — Rome — €26,800 gross/year — [official posting](https://amazon.jobs/en/jobs/10425214/hr-specialist-with-italian-english-fixed-term-contract-12-months-disability-leave-services)
- Data Center Technician, 2027 Internship — Milan — €1,080 gross/month — [official posting](https://amazon.jobs/en-gb/jobs/10567698/data-center-technician-2027-internship)
- Operations Manager, FC Operations — Alessandria — €64,800 gross/year — [official posting](https://www.amazon.jobs/en/jobs/10516571/operations-manager-fc-operations)

Salary figures are copied only where stated by the employer and are gross, not net. Role requirements, location and contract terms can change; applicants must check the original posting before applying. No visa sponsorship is inferred. The HR listing notes a protected-category preference/criterion, which is preserved in the summary.

## Publishing and freshness

- Local/testing seed runs publish these records so developers can review the jobs UI.
- Other environments seed them as hidden until a human verifies and publishes them through the normal admin process.
- Listings have a short expiry date and must be rechecked before extending it.
- The source record is inactive and has no importer configuration: these are manually curated links, not a claim that an automated feed has been connected.
- This is the first verified batch, not full Italy-wide coverage. Expand with more employers and job categories only after checking each live original listing and respecting its source terms.
